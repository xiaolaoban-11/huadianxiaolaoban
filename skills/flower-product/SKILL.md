# 花束产品策划

## 适用时机
用户需要花束产品策划时使用；先确认输入数据有来源，缺失信息要显式标注，不编造事实。

## 输入
鲜花库存、进货价、人工包装费、配送费、目标毛利、销售城市。

## 执行步骤
1. 读取本次输入与上游产物，核实来源、时效和商品信息；将未知项列为待确认。
2. 按本 Skill 的业务目标整理信息，关联来源链接、商品 ID、笔记 ID 或订单 ID（按需）。
3. 只提出能由证据支持的洞察与建议；对竞品内容只分析结构，不复制受版权保护的图片或文案。
4. 输出表格或清单及行动建议，标明负责人、人为审核点与下一环节交接字段。

## 输出格式
产品卡、成本核算、价格建议区间、替代花材、配送和售后注意事项。

## 验收标准
- 输入可追溯且关键字段完整，缺失项明确标记。
- 输出可直接交给下一个 Skill，字段命名一致。
- 价格、花材、库存、配送时效、销量及评价不得虚构。
- 未经人工审核不得自动发布或自动回复顾客；遵守平台条款和数据保护要求。

## 对接
参照仓库 README 所列业务流程，上游产物按统一商品、笔记与订单标识关联。后续如使用 n8n，调用本 Skill 的输入/输出约定，不假设已有可用 API。
